# LinxSci 0.3.3

[English](v0.3.3.md)

基础 AI Skill 更名为 `linxsci-base`，新安装默认使用 `~/.agents/skills/linxsci-base`。Python 包、终端命令及 SDK 导入名继续使用 `linxsci`。

- Skill 源码迁至 `skills/linxsci-base`，同步打包配置、安装命令和中英文文档。
- 支持使用 `--update` 迁移本工具管理的旧版 `linxsci-skills`。旧副本备份到助手扫描目录之外，安装失败时恢复；未受管理的副本、符号链接或新旧目录冲突时保留原文件，由原安装方式处理迁移。
- API 方法、全部 34 条已文档化路由及 `LINXSCI_*` 配置保持兼容。配置位置继续使用 macOS/Linux 的 `~/.config/linxsci-skills/config.json`，以及 Windows 的 `%LOCALAPPDATA%\linxsci-skills\config.json`。
- 从公开安装包排除本地设置、笔记和生成文件，校验完整 Skill 资源、包内链接、版本及校验和。

## 升级方式

待该版本在 PyPI 可用后，在 CLI 或应用实际使用的 Python 环境中运行：

```bash
python -m pip install --upgrade --index-url https://pypi.org/simple linxsci==0.3.3
linxsci --version
```

SDK 继续使用 `from linxsci import LinxSciClient`。使用 uv 管理的 CLI，通过 `uv tool upgrade linxsci` 更新。

升级 Python 包不会自动更新已复制到助手目录的 Skill。对于本工具管理的 Skill，使用新版 CLI 执行 `linxsci install-skill --update`；或解压新版独立 ZIP，在其中运行：

```bash
python3 install.py --update --no-config
```

Windows 使用 `py -3 install.py --update --no-config`。自定义安装父目录需再次指定 `--skills-dir PATH`。迁移后刷新助手。外部安装器管理的 Skill 使用原安装器更新；已有 API Key 和保存的设置继续有效。
