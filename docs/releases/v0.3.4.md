# LinxSci 0.3.4

[简体中文](https://github.com/LinxSci/linxsci-skills/blob/v0.3.4/docs/releases/v0.3.4.zh-CN.md)

The base CLI now discovers installed Skills and forwards commands to their Python scripts. Adding a conforming Skill no longer requires another base-package release or a separate Python distribution for that Skill. The CLI and SDK continue to ship together as `linxsci`.

- Discover Skills directly under `~/.agents/skills`, or set `LINXSCI_SKILLS_DIR` to an absolute parent directory. A Skill must contain `SKILL.md` and `scripts/<name>.py`; hyphens in the command name become underscores in the script filename.
- Run installed extensions with commands such as `linxsci paper-qa ...` and `linxsci survey ...`. Arguments, the caller's working directory, environment, standard streams and exit status are preserved. Discovery lists available commands without executing Skill code.
- Built-in commands retain precedence. Use `linxsci skill paper ...` for the `linxsci-paper` extension because `linxsci paper ...` already reads the base paper API.
- Preserve existing SDK imports, all 34 documented API routes and saved configuration. Skill scripts run with the CLI's Python interpreter; install their dependencies in that environment.
- Add the [API key page](https://linxsci.com/open-api?tab=keys) to setup instructions and include dispatch support in the wheel and standalone Skill bundle.

## Install or upgrade

Once this version is available on PyPI, run in the environment used by your CLI or application:

```bash
python -m pip install --upgrade --index-url https://pypi.org/simple linxsci==0.3.4
linxsci --version
```

SDK code continues to use `from linxsci import LinxSciClient`. For a uv-managed CLI, use `uv tool upgrade linxsci`.

Install complete extension Skill folders separately. Short commands become available when those folders are discoverable; the base package does not include or install the extensions. If an extension pins `linxsci` to an older version, installing its requirements can downgrade the CLI. Update that constraint after compatibility validation, or install its dependencies before upgrading the base package.

For an installer-managed copy of `linxsci-base`, run `linxsci install-skill --update`, or extract the new standalone ZIP and run `python3 install.py --update --no-config` (`py -3` on Windows). Use the original installer for externally managed copies. Existing API keys and saved settings remain valid.
