# LinxSci 0.3.1

[简体中文](https://github.com/LinxSci/linxsci-skills/blob/v0.3.1/docs/releases/v0.3.1.zh-CN.md)

- Separate the bilingual Skill, CLI and Python SDK guides, including installation, configuration, updates and removal.
- Make the standalone Skill ZIP open with the Skill user guide and assistant examples. Retain the complete bundled scripts and agent references without requiring another package.
- Document ZIP installation as an alternative when repository cloning times out.

- Validate package contents, versions, checksums and fresh installations before publication.

## Downloads

| File | Purpose |
| --- | --- |
| `linxsci-skills-0.3.1.zip` | Standalone Skill installer for macOS, Windows and Linux |
| `linxsci-0.3.1-py3-none-any.whl` | Python distribution providing the `linxsci` terminal command and Python SDK |
| `linxsci-0.3.1.tar.gz` | Source distribution |
| `SHA256SUMS` | SHA-256 checksums for the three packages |

The Skill ZIP requires Python 3.9+ and an assistant that supports local skills. Extract it, then run `python3 install.py` (`py -3 install.py` on Windows). For a managed existing copy, run the new bundle's `python3 install.py --update --no-config` and reuse any custom `--skills-dir` option.

Install the wheel into the Python environment you use: `python -m pip install --upgrade ./linxsci-0.3.1-py3-none-any.whl`. Configure terminal use with `linxsci setup`; configure SDK use with `LinxSciClient` constructor arguments or environment variables. See the separate guides in the repository for details.

Existing settings are preserved. Published older packages are not overwritten.
