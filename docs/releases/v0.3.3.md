# LinxSci 0.3.3

[简体中文](https://github.com/LinxSci/linxsci-skills/blob/v0.3.3/docs/releases/v0.3.3.zh-CN.md)

The foundational AI Skill is now named `linxsci-base`. New installations use `~/.agents/skills/linxsci-base`; the Python package, terminal command and SDK imports remain `linxsci`.

- Move the Skill source to `skills/linxsci-base` and update packaging, installation commands and bilingual documentation.
- Migrate managed `linxsci-skills` installations with `--update`. Keep the old copy in a backup outside the assistant scan directory and restore it if installation fails. Unmanaged copies, symlinks and conflicting old/new installations are left untouched for migration through their original installer.
- Preserve API methods, the 34 documented routes, `LINXSCI_*` settings and the existing configuration paths: `~/.config/linxsci-skills/config.json` on macOS/Linux and `%LOCALAPPDATA%\linxsci-skills\config.json` on Windows.
- Exclude local settings, notes and generated files from public packages. Validate complete Skill resources, archive links, versions and checksums.

## Upgrade

In the Python environment used by your CLI or application, after this version is available on PyPI:

```bash
python -m pip install --upgrade --index-url https://pypi.org/simple linxsci==0.3.3
linxsci --version
```

SDK imports remain `from linxsci import LinxSciClient`. For uv-managed CLI installations, use `uv tool upgrade linxsci`.

Updating the Python package does not update a Skill already copied into an assistant directory. For a managed Skill, run the new CLI's `linxsci install-skill --update`, or extract the new standalone ZIP and run:

```bash
python3 install.py --update --no-config
```

On Windows use `py -3 install.py --update --no-config`. Repeat `--skills-dir PATH` for a custom installation parent. Refresh the assistant after migration. Update externally managed Skills using their original installer; existing API keys and saved settings remain valid.

See the [Skill](https://github.com/LinxSci/linxsci-skills/blob/v0.3.3/docs/USER_GUIDE.md), [CLI](https://github.com/LinxSci/linxsci-skills/blob/v0.3.3/docs/CLI_GUIDE.md) and [SDK](https://github.com/LinxSci/linxsci-skills/blob/v0.3.3/docs/DEVELOPMENT.md) guides. Release validation covers regression tests, source archive rebuilds, wheel/ZIP/uv installations and old-name migration against a local mock API.
