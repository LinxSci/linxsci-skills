# LinxSci 0.3.5

[English](v0.3.5.md)

安装 `linxsci-base` 后，用户可以让当前 Agent 查看可选 LinxSci Skill，并从各自的 GitHub 仓库按需安装。完整扩展目录和安装引导现已随 base 一起包含在独立 ZIP 和 Python 包中。

- 提供七个可选 Skill，覆盖文献综述、研究构思、论文问答、论文写作、演示文稿、代码复现和小红书图文。Agent 检查真实安装状态，安装所选 Skill 和依赖，配置发现并验证入口。
- 任务中缺少协作者时，可安装后保留原材料、工作目录和输出位置继续执行。根据 Agent 的发现约定支持项目级或用户级安装。
- base 安装完成后显示扩展提示和本地指南路径。stdout JSON 保留 `installed`、`skill` 和可选 `backup`，新增 `extension_guides`、`next_steps`；可读提示输出到 stderr。base 安装过程不下载扩展。
- 配置失败或取消时单独说明未完成状态，保留已安装的 base 和已有配置。
- 扩展通过各自 GitHub 源码仓库安装，相应更新了 base 任务路由、独立仓库文档及打包检查。

## 安装或升级

CLI 与 SDK 在实际使用的 Python 环境中执行：

```bash
python -m pip install --upgrade --index-url https://pypi.org/simple linxsci==0.3.5
linxsci --version
```

继续支持 Python 3.9+，SDK 导入和 API 路由保持兼容。当前扩展仍固定依赖 `linxsci==0.3.4`；按目标仓库 requirements 使用单独的兼容环境，避免降级已有 `0.3.5` CLI/SDK 环境。base 随附脚本可独立于扩展环境运行。

更新本安装器管理的 base 副本时，解压新 ZIP 并运行 `python3 install.py --update --no-config`（Windows：`py -3 install.py --update --no-config`），或使用新版 CLI 执行 `linxsci install-skill --update`。自定义安装目录需沿用原路径；其他安装器管理的副本沿用对应工具更新。更新后刷新助手；仅升级 Python 包不会更新已复制的 Skill。

随后可以对 Agent 说：

```text
使用 $linxsci-base 列出 LinxSci 可选 Skill 并检查哪些已安装。将 linxsci-paper 安装到当前项目的 Skill 发现目录，准备依赖并验证 linxsci skill paper --help。
```

Agent 需要终端、文件操作能力，以及目标扩展仓库的访问权限。扩展分别获取；发布 base 不会同时发布这些扩展仓库。
