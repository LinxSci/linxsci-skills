# LinxSci 0.3.4

[English](v0.3.4.md)

基础 CLI 新增已安装 Skill 的自动发现和脚本转发。新增符合约定的 Skill 无需再次发布基础包，也无需为该 Skill 创建独立 Python 安装包。CLI 与 SDK 继续由同一个 `linxsci` 包提供。

- 默认发现 `~/.agents/skills` 下的 Skill，也可通过 `LINXSCI_SKILLS_DIR` 指定绝对父目录。Skill 根目录需有 `SKILL.md` 和 `scripts/<名称>.py`；脚本文件名中的连字符转换为下划线。
- 已安装的扩展可使用 `linxsci paper-qa ...`、`linxsci survey ...` 等短命令。保留参数、调用目录、环境配置、标准输入输出和退出状态；列出可用命令时不执行 Skill 代码。
- 基础命令优先。`linxsci paper ...` 继续访问基础论文接口；调用 `linxsci-paper` 扩展使用 `linxsci skill paper ...`。
- 原有 SDK 导入、全部 34 条已文档化 API 路由和已保存配置保持兼容。Skill 脚本使用 CLI 所在的 Python 解释器，依赖需安装到同一环境。
- 配置说明补充 [API Key 获取入口](https://linxsci.com/open-api?tab=keys)，wheel 与独立 Skill 安装包均包含转发能力。

## 安装或升级

待该版本在 PyPI 可用后，在 CLI 或应用实际使用的 Python 环境中运行：

```bash
python -m pip install --upgrade --index-url https://pypi.org/simple linxsci==0.3.4
linxsci --version
```

SDK 继续使用 `from linxsci import LinxSciClient`。uv 管理的 CLI 使用 `uv tool upgrade linxsci` 更新。

扩展 Skill 的完整文件夹需单独安装，放入发现目录后才能使用对应短命令；基础包不包含或自动安装这些扩展。若扩展的依赖固定了旧版 `linxsci`，安装其依赖可能降级 CLI。通过兼容验证后更新该依赖约束，或先安装扩展依赖，再升级基础包。

本工具管理的 `linxsci-base` 副本使用 `linxsci install-skill --update` 更新；也可解压新版独立 ZIP，在其中运行 `python3 install.py --update --no-config`（Windows 使用 `py -3`）。外部安装器管理的副本沿用原安装器更新。已有 API Key 和保存的设置继续有效。
