## 下载文件

| 文件 | 用途 |
| --- | --- |
| `linxsci-skills-0.3.1.zip` | macOS、Windows 和 Linux 独立 Skill 安装器 |
| `linxsci-0.3.1-py3-none-any.whl` | 提供 `linxsci` 终端命令及 Python SDK 的 Python 安装包 |
| `linxsci-0.3.1.tar.gz` | 源码包 |
| `SHA256SUMS` | 三个安装包的 SHA-256 校验和 |

Skill ZIP 需要 Python 3.9+ 和支持本地 Skill 的助手。解压后运行 `python3 install.py`，Windows 使用 `py -3 install.py`。已有自带安装器管理的副本时，从新版目录执行 `python3 install.py --update --no-config`，并补充原先自定义的 `--skills-dir`。

在实际使用的 Python 环境安装 wheel：`python -m pip install --upgrade ./linxsci-0.3.1-py3-none-any.whl`。终端使用通过 `linxsci setup` 配置；SDK 通过 `LinxSciClient` 构造参数或环境变量配置。完整说明见仓库内各自的指南。

更新保留已有设置，不覆盖已发布的旧版安装包。
