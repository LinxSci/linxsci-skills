# LinxSci 0.3.2

[English](v0.3.2.md)

- 优化 Skill 论文筛选：先确认真实响应字段，精简候选，再比较入选候选的摘要，说明检索范围和证据来源。接口分数仅作为排序信号，不解释为相关性百分比。
- 独立脚本和 CLI 增加结构化字段诊断：缺失字段、可用字段及首条出错记录的位置。保留原有错误码和成功响应格式。
- 接口成功后，本地筛选失败仍保留原始响应，可以通过 `read-output` 修正，无需重复请求。
- 完善独立的中英文 CLI、SDK 安装说明，补充验证、更新、离线 wheel 安装和 TLS 故障排查。
- Python SDK 接口及原始响应行为不变。仍支持 Python 3.9+，无额外运行时依赖。

## 下载与更新

| 文件 | 用途 |
| --- | --- |
| `linxsci-skills-0.3.2.zip` | 独立 Skill 安装器及完整 Agent 资源 |
| `linxsci-0.3.2-py3-none-any.whl` | Python SDK 和 CLI 安装包 |
| `linxsci-0.3.2.tar.gz` | 源码包 |
| `SHA256SUMS` | 三个安装包的 SHA-256 校验和 |

对于受安装器管理的 Skill，解压新 ZIP 后运行 `python3 install.py --update --no-config`（Windows 使用 `py -3 install.py --update --no-config`），保留自定义 `--skills-dir` 参数并刷新助手。现有配置继续保留。

对于 pip 安装的 SDK 或 CLI，激活原环境，待 PyPI 上该版本可用后运行 `python -m pip install --upgrade --index-url https://pypi.org/simple linxsci==0.3.2`。使用 uv tool 管理的安装通过 `uv tool upgrade linxsci` 更新。也可直接安装本次发布的 wheel。

完整说明分别见 [Skill](https://github.com/LinxSci/linxsci-skills/blob/v0.3.2/docs/USER_GUIDE.zh-CN.md)、[CLI](https://github.com/LinxSci/linxsci-skills/blob/v0.3.2/docs/CLI_GUIDE.zh-CN.md) 和 [SDK](https://github.com/LinxSci/linxsci-skills/blob/v0.3.2/docs/DEVELOPMENT.zh-CN.md) 指南。

验证覆盖 51 项回归测试、Skill 格式、文档、安装包校验及隔离安装冒烟测试。历史发布版本保持不变。
