# LinxSci 0.3.5

[简体中文](https://github.com/LinxSci/linxsci-skills/blob/v0.3.5/docs/releases/v0.3.5.zh-CN.md)

After installing `linxsci-base`, users can ask their Agent to discover and install optional LinxSci Skills from their individual GitHub repositories. The complete extension catalog and installation guidance now travel with base in both the standalone ZIP and Python package.

- Discover seven optional Skills for surveys, research ideas, paper Q&A, paper writing, presentations, reproduction and Xiaohongshu content. The Agent checks actual installation status, installs the selected Skill and its dependencies, configures discovery and verifies its entrypoint.
- Install missing collaborators during a task, then continue with the original materials, working directory and output location. Project and user installation scopes are supported according to the Agent's discovery conventions.
- Base installation prints optional-extension guidance and local guide paths. JSON stdout retains `installed`, `skill` and optional `backup`, adding `extension_guides` and `next_steps`; readable guidance goes to stderr. Base installation does not download extensions.
- Configuration failure or cancellation reports the incomplete setup separately while preserving installed base files and existing configuration.
- Extensions use their individual GitHub source repositories. Base task routing, independent-repository documentation and release packaging checks are updated accordingly.

## Install or upgrade

For the CLI and SDK, run in the intended Python environment:

```bash
python -m pip install --upgrade --index-url https://pypi.org/simple linxsci==0.3.5
linxsci --version
```

Python 3.9+ remains supported. The SDK imports and API routes are unchanged. Current extensions still pin `linxsci==0.3.4`; follow each repository's requirements and use a separate compatible environment instead of downgrading an existing `0.3.5` CLI/SDK environment. Base's bundled scripts work independently of that extension environment.

To update an installer-managed base copy, extract the new ZIP and run `python3 install.py --update --no-config` (Windows: `py -3 install.py --update --no-config`), or use the new CLI's `linxsci install-skill --update`. Preserve the original custom installation directory if applicable. Copies managed by another installer must be updated with that installer. Refresh the assistant after updating; upgrading the Python package alone does not update a previously copied Skill.

Then ask your Agent:

```text
Use $linxsci-base to list optional LinxSci Skills and check which are installed. Install linxsci-paper into this project's Skill discovery directory, prepare its dependencies and verify linxsci skill paper --help.
```

The Agent needs terminal/file access and access to the selected extension's repository. Each extension is obtained separately; base releases do not publish those repositories.
