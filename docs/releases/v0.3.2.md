# LinxSci 0.3.2

[简体中文](https://github.com/LinxSci/linxsci-skills/blob/v0.3.2/docs/releases/v0.3.2.zh-CN.md)

- Improve Skill paper selection: inspect actual response fields, screen concise candidates, compare shortlisted abstracts, and explain the search scope and evidence used. Treat service scores as ranking signals rather than relevance percentages.
- Add structured field diagnostics to the standalone script and CLI: missing keys, available keys and the first failing record's position. Existing error codes and successful response formats remain compatible.
- Preserve successful API responses when a local projection fails, allowing correction through `read-output` without repeating the request.
- Expand separate bilingual CLI and SDK installation instructions, including verification, updates, offline wheel installation and TLS troubleshooting.
- Keep the Python SDK interface and raw response behavior unchanged. Runtime requirements remain Python 3.9+ with no additional dependencies.

## Downloads and updates

| File | Purpose |
| --- | --- |
| `linxsci-skills-0.3.2.zip` | Standalone Skill installer and complete agent resources |
| `linxsci-0.3.2-py3-none-any.whl` | Python SDK and CLI installation package |
| `linxsci-0.3.2.tar.gz` | Source distribution |
| `SHA256SUMS` | SHA-256 checksums for all three packages |

For a managed Skill installation, extract the new ZIP and run `python3 install.py --update --no-config` (`py -3 install.py --update --no-config` on Windows). Repeat any custom `--skills-dir` option and refresh your assistant. Existing settings are preserved.

For a pip-managed SDK or CLI installation, activate its environment and run `python -m pip install --upgrade --index-url https://pypi.org/simple linxsci==0.3.2` after the version is available on PyPI. For an installation managed by uv tool, use `uv tool upgrade linxsci`. The wheel can also be installed directly from this release.

See the separate [Skill](https://github.com/LinxSci/linxsci-skills/blob/v0.3.2/docs/USER_GUIDE.md), [CLI](https://github.com/LinxSci/linxsci-skills/blob/v0.3.2/docs/CLI_GUIDE.md) and [SDK](https://github.com/LinxSci/linxsci-skills/blob/v0.3.2/docs/DEVELOPMENT.md) guides.

Validation includes 51 regression tests, Skill validation, documentation checks, package validation and isolated installation smoke tests. Previously published versions remain unchanged.
